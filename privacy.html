와르르 연쇄 개인정보처리방침

시행일 2026년 11월 5일 · 개발자 gksx2006-jpg

와르르 연쇄(이하 "게임")는 이용자의 개인정보를 수집하지 않습니다. 이 문서는 게임이 어떤 정보를 다루는지 설명합니다.

1. 수집하는 정보

게임은 이름, 이메일, 전화번호, 위치, 기기 식별자 같은 개인정보를 수집하지 않습니다. 회원가입과 로그인 기능도 없습니다.

2. 기기 안에만 저장되는 정보

게임 진행 상황(레벨별 별 개수)과 소리 켬·끔 설정은 이용자의 기기 안에만 저장됩니다. 이 정보는 개발자나 다른 누구에게도 전송되지 않습니다. 앱을 지우거나 브라우저 데이터를 지우면 함께 삭제됩니다.

3. 광고와 분석

게임에는 광고, 분석 도구, 결제 기능이 없습니다.

4. 외부 서비스

  • 게임 파일은 GitHub Pages(GitHub, Inc.)에서 제공됩니다. 접속할 때 GitHub가 IP 주소 같은 기술 정보를 보안 목적으로 기록할 수 있습니다.
  • 화면 글꼴은 Google Fonts(Google LLC)에서 불러옵니다. 이때 Google이 IP 주소 같은 기술 정보를 받을 수 있습니다.

이 정보는 각 회사의 개인정보처리방침에 따라 처리되며, 개발자는 이 정보를 받거나 볼 수 없습니다.

5. 아동의 개인정보

게임은 누구의 개인정보도 수집하지 않으므로, 만 14세 미만 아동의 개인정보도 수집하지 않습니다.

6. 방침의 변경

이 방침이 바뀌면 이 페이지에 새 내용과 시행일을 올립니다.

7. 문의

문의는 GitHub 문의 게시판에 남겨 주세요.

Privacy Policy (English summary)

Effective November 5, 2026. Wareureu Chain (와르르 연쇄) does not collect any personal information. There is no account, no advertising, no analytics and no payment.

Game progress (stars per level) and the sound setting are stored only on your device and are never sent to the developer. The game files are served by GitHub Pages and the fonts by Google Fonts. These services may receive technical data such as your IP address under their own privacy policies. The developer does not receive this data.

Contact: GitHub issues.
